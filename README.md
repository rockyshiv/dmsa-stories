# DMSA player stories - interview page

Private interview page for players of Divyaang Myithri Sports Academy (DMSA).
Each player opens a personal link (`https://rockyshiv.github.io/dmsa-stories/?c=CODE`),
talks with Maitri, DMSA's AI story volunteer, on video, and uploads photos.

Recordings, transcripts and uploads go to DMSA's Google Drive through a Google Apps
Script backend; this site only hosts the page.

To republish after a change: `npm run build`, then push the contents of `out/`
(plus an empty `.nojekyll` file) to the `gh-pages` branch.
